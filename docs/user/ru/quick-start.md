# Быстрый старт

[Документация](../../README.md) · [English](../quick-start.md) · [Руководство пользователя](guide.md)

Transcribe v0.5.0 распознаёт русскую речь локально на CPU. GUI поддерживает
русский и английский языки; консольный вывод CLI остаётся русским.

## Загрузка

Скачайте пакет для своей ОС из [v0.5.0](https://github.com/khdobromir/transcriber/releases/tag/v0.5.0):

- [Linux AppImage](https://github.com/khdobromir/transcriber/releases/download/v0.5.0/Transcribe-0.5.0-linux-x86_64.AppImage):
  x86_64, glibc 2.39+.
- [Windows ZIP](https://github.com/khdobromir/transcriber/releases/download/v0.5.0/Transcribe-0.5.0-windows-x64.zip):
  Windows 11 x64.

Модели скачиваются отдельно. Архивы исходников и build-inputs нужны разработчикам.
Для бинарных пакетов не требуются отдельные Qt SDK, Python, компилятор и медиапрограммы.

## Проверка и запуск

Сравните SHA-256 с digest **того же файла** на странице GitHub Release
(раскройте сведения о файле). Отдельные файлы контрольных сумм не публикуются.

Linux:

```sh
sha256sum Transcribe-0.5.0-linux-x86_64.AppImage
chmod +x Transcribe-0.5.0-linux-x86_64.AppImage
./Transcribe-0.5.0-linux-x86_64.AppImage
```

Если FUSE недоступен, используйте тот же файл с параметром распаковки;
понадобится место для временных файлов:

```sh
./Transcribe-0.5.0-linux-x86_64.AppImage --appimage-extract-and-run
```

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Transcribe-0.5.0-windows-x64.zip'
```

После проверки распакуйте **весь ZIP**, сохранив его каталоги, и запустите
`bin\transcribe-gui.exe`. Встроенные инструменты должны оставаться вместе.

## Подготовка моделей и расшифровка

1. На странице **Расшифровка** выберите `small` для первого теста.
   Свежий GUI выбирает `medium`, которая может работать дольше.
2. Откройте **Модели**, нажмите **Скачать small и VAD** и дождитесь успешной проверки.
   Для первого запуска без сети заранее получите точные файлы распознавания и VAD
   из [манифеста моделей](../../../scripts/models.tsv), затем используйте
   **Импорт small…** и **Импорт VAD…**. Перед импортом выберите соответствующий пресет.
3. Вернитесь на **Расшифровка**, выберите свою локальную запись и каталог результатов.
   Оставьте одну часть и автоматические потоки, затем нажмите **Начать расшифровку**.
4. Дождитесь статуса **Готово** и откройте **Каталог** или **Полный TXT**.
   Каждый запуск содержит `transcripts/transcript.txt`, `.srt`, `.vtt`, `logs/`,
   `source.txt` и `result.json`. Предпросмотр и 100% прогресса ещё не подтверждают сохранение экспорта.

Переключатель языка на странице **Настройки** предлагает
**Автоматически / Automatic**, **Русский** и **English**. Автоматический режим
выбирает русский для русской системы, английский — для остальных. Выбор сохраняется
и применяется сразу, с сохранением текущей работы. Язык распознавания и CLI
остаётся русским; системные диалоги могут сохранять язык ОС.

После подготовки моделей локальная запись обрабатывается без сети. URL и загрузка
моделей требуют интернет. **Отменить** сохраняет опубликованный частичный текст;
повтор запускает распознавание заново. При проблемах см.
[устранение неполадок](../../troubleshooting.md).

Для CLI предусмотрен отдельный сценарий: Windows ZIP содержит `bin\transcribe.exe`,
а Linux AppImage не устанавливает команду в PATH. См.
[быстрый старт CLI](../../../README.md#быстрый-старт-cli),
[зависимости установщика](../../build/from-source.md#linux-cli-source-installer)
и [справочник CLI](../cli.md).
